# Fase 4 — pacote visual 32-bit

Este diretório contém o pacote visual da Fase 4 (`Água pOtávio`).

O runtime usa um atlas PNG composto com as artes de:
- Shall Mexilhãozinho;
- Água pOtávio;
- inimigos aquáticos;
- tileset;
- background, midground e foreground;
- VFX aquáticos.

A arte foi preparada para uso em Canvas 2D com `imageSmoothingEnabled = false` e recortes via `drawImage()`.
